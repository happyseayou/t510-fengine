# Stage 33a：ADC 固定杂散定责与终止归档

## 终止性能结论

`TERMINATED / ACCEPTED_WITH_KNOWN_LIMITATIONS / NO_PRODUCTION_MITIGATION`

- **DAC用于功能回环足够。** 频谱仪在约20 dB低噪放后测得100 MHz主音
  `3.84 dBm`；除200 MHz外，60/120/140/160/180/220 MHz的20 MHz栅格为
  `-84.88..-91.26 dBc`。仪表噪声约`-92..-94 dBm/1 kHz RBW`，相对主音为
  `-95.84..-97.84 dBc`。200 MHz二次谐波为`-61.88 dBc`，本次不再区分DAC与
  中间低噪放的贡献。该性能足以验证通道映射、频率、同步及强信号回环，但不能把
  板内DAC当作高动态范围频谱纯度信号源。ADC回环内仍见约`-66..-76 dBc`梳状，
  不能全部归因于DAC。
- **ADC用于一般采集足够，但三处窄带受限。** RFDC内部固定杂散分别为480 MHz
  `-89.75..-85.00 dBFS`、960 MHz `-93.95..-88.23 dBFS`、1440 MHz
  `-88.25..-82.64 dBFS`；最坏约`2.42 ADU`，偏移复核相对局部背景突出约
  `26.63..32.62 dB`。
- 三处固定项不影响宽带总功率、普通时域波形、吞吐和防clip裕量，但不会随积分下降，
  且跨ADC相干度最高接近0.99。480/960/1440 MHz邻近bin不得用于无条件的长积分弱
  谱线或互相关结论。Stage 33总体保持`RF_PARTIAL`，但满足当前工程和功能验证用途。
- Stage 33a在此终止：不实施OCB1 override、notch、持续自适应抵消、前馈扣除或新的
  RTL修复。未来如需重新追求三处频点的科学动态范围，另立新阶段重新定义门禁。

## 阶段状态

`CHARACTERIZATION_COMPLETE / MITIGATION_REJECTED_FOR_PRODUCTION / TERMINATED`

Stage 33a 是 Stage 33 的原位后续，不是独立工程或新发布分支。Stage 33 已经完成的
`3.84 GS/s + 12x` RFDC、320 MS/s 复基带、80 MHz AXIS、PFB、TIME/SPEC、UDP 和
Rust 接收合同全部保持不变。本阶段只归档 ADC 固定杂散证据、清理被最终实验取代的
记录，并冻结下一步修复建议；没有修改 RTL、bitstream、API 或生产 RFDC 配置。

当前生产配置继续保持 ADC dither 开启和正常 OCB1 后台校准。实验性的OCB1 override
和复矢量扣除不进入生产。

## 结论摘要

- 480、960、1440 MHz 是八路 ADC、160/320 MS/s 两种模式共同复现的主固定杂散，
  分别对应 `Fs/8`、`Fs/4`、`3Fs/8`。
- 160、1120、1280、1600 MHz 是偏移复核后仍存在的较弱观察项；800 MHz仅单路略过
  门限，1760 MHz未确认，均不进入首轮修复频点。
- 三条主线的 raw-preview 绝对幅度为 `-93.95..-82.64 dBFS`，最坏约2.42 ADU。
  它们不会造成宽带灵敏度、防 clip 裕量或普通时域波形整体失效，但会形成不会随积分
  下降的固定单 bin floor，污染长积分弱谱线及同频互相关结果。
- 改变 ADC NCO 后，峰在复基带内移动但还原后的物理 RF 不变；PFB 前 raw preview、
  PFB SPEC 和原始 UDP 均看到相同频点。ADC 连接器侧SSA在100 Hz RBW下只看到约
  `-113 dBm`噪声。因此TG、DAC、线缆、DDC、PFB、packetizer、CMAC、Rust和Web均
  不是生成源，分类为RFADC内部时间交织残差。
- OCB1后台系数变化与峰的幅相游走直接相关。锁住当前OCB1可以稳定峰，但不能独立
  消除仍高于噪声约9..11.5 dB的残余。

原始PCAP、JSON、扫描图和Vivado运行报告已按latest-only仓库策略清理；本报告保留
最终方法、关键数值、判定边界和阶段结论，不依赖已清理的运行目录作为活动链接。

## 定责证据链

### RTL与频率坐标

`rfdc_adc_axis_adapter`只把RFDC AXIS中的I/Q半字重新打包。诊断raw preview在
science rate selector、PFB、packetizer和CMAC之前取数，因此raw层已经看到的固定峰
不可能由这些后级模块产生。

在DAC物理断开且没有外部信号源时，把ADC NCO中心依次设为840、900、940、960、
980、1020和1080 MHz，固定峰分别落在复基带`+120/+60/+20/0/-20/-60/-120 MHz`，
映射回物理RF始终为960 MHz。原始NCO/raw-preview扫描已在清理前复核，其最终频率
映射和数值固化于本报告。

这同时解释了Stage 32与Stage 33的差别：Stage 32的ADC采样率为1.6 GS/s，`Fs/4`
位于400 MHz；Stage 33把模拟采样率升级到3.84 GS/s，固定交织位置随之移动到
960 MHz。两个阶段的320 MS/s复基带、80 MHz AXIS和science数据面没有产生相应的
新周期源，不能通过回退Stage 32已经验收的adapter/PFB/UDP来修复。

### 第一Nyquist全带复核

160 MS/s模式使用80..1840 MHz、步进80 MHz共23窗；320 MS/s模式使用
160..1760 MHz、步进160 MHz共11窗。每窗都采集八路原始SPEC UDP，合计34个主窗口。
另在160 MS/s下把9个候选的NCO中心偏移40 MHz，使目标RF不再落在center bin，完成
9个偏移窗口。43份PCAP共22,016包、184,451,080字节，活动采集窗口内RFDC和主机
drop/gap均为零。

| 物理RF | 交织位置 | 八路/双模式 | 偏移复核 | raw绝对幅度 | 分类 |
| ---: | ---: | :---: | :---: | ---: | --- |
| 480 MHz | `Fs/8` | 是 | 29.62 dB | `-89.75..-85.00 dBFS` | 主固定杂散 |
| 960 MHz | `Fs/4` | 是 | 32.62 dB | `-93.95..-88.23 dBFS` | 主固定杂散 |

| 1120 MHz | 160 MHz网格 | 部分通道 | 8.97 dB | 未做SSA定责 | 较弱观察项 |
| 1280 MHz | 160 MHz网格 | 部分通道 | 8.92 dB | 未做SSA定责 | 较弱观察项 |

主扫描、拼接、候选表、偏移复核以及双模式raw/PFB结果已在清理前完成一致性审计；
43窗口、包数、字节数及最终频点表由本节作为长期记录保留。

### 连接器侧与校准状态

在DAC断开、TG关闭、ADC0/ADC2经功分接SSA 50 Ω输入时，SSA对480、960、1440 MHz
的100 Hz RBW复测均只看到约`-113 dBm`噪声；相同条件下RFDC raw preview仍看到
相干固定峰。这排除了连接器侧可测窄线注入，但不把结论扩大为板上所有节点都不存在
时钟耦合。

RFDC reset和50 Ω前景校准会改变峰的幅相，并可短时降低个别通道，但15秒内OCB1
后台过程再次改变结果。CalFreeze按器件设计冻结GCB/TSCB而不冻结OCB1；修正判据后
GCB/TSCB及前景OCB2均保持不变，OCB1仍变化，固定峰也没有系统性改善。

## 已尝试方案与判定

| 方案 | 实测结果 | Stage 33a判定 |
| --- | --- | --- |
| RFDC reset/50 Ω前景校准 | 能改变并短时降低部分通道，但会随OCB1继续漂移 | 只作为受控校准步骤，不能单独修复 |
| AutoCal候选bitstream | 960 MHz仍固定映回原RF，强度未改善 | 否决；不提升catalog |
| CalFreeze | GCB/TSCB冻结，OCB1按设计继续变化；主峰无系统改善 | 否决为单独修复 |
| 关闭dither | 噪声底约降1.3 dB，绝对固定峰未下降 | 否决；生产继续开启dither |
| DSA衰减 | 只牺牲输入信号和动态范围，不能消除绝对固定分量 | 否决 |
| OCB1原值override | 峰幅相稳定，但仍高于噪声约9..11.5 dB | 仅限定责；不是生产修复 |
| 一次静态复矢量扣除 | OCB1游走使15秒残余重新升高 | 否决长期静态常数 |
| 持续自适应扣除/notch | 无法区分内部项和同频真实谱线 | 禁止用于完整科学通带 |
| OCB1锁定＋静态扣除模型 | ADC0/ADC2三频点60秒残余约2.42..3.13 dB高于噪声 | 保留为有条件候选，尚未生产验收 |

OCB1锁定模型的60秒结果为：

| 固定RF | ADC0抑制/残余 | ADC2抑制/残余 |
| ---: | ---: | ---: |
| 480 MHz | 15.63/2.82 dB | 17.09/2.97 dB |
| 960 MHz | 17.78/3.13 dB | 11.49/2.60 dB |
| 1440 MHz | 9.52/2.63 dB | 16.79/2.42 dB |

这些结果仍只是ADC0/ADC2、受控50 Ω条件下的离线模型，没有验证八路、同频弱信号
保真、温漂、复位重复性或无需人工终端的校准流程。

## 科学性能边界

- 对总功率、连续谱、普通时域波形和防clip裕量，最坏2.42 code的贡献可忽略，不会
  造成0..1.92 GHz整个频带失效。
- 对强窄带输入，相对影响取决于信号幅度。例如`-20 dBFS`信号相对最坏固定项约
  `-62.6 dBc`，而`-40 dBFS`信号只约`-42.6 dBc`，不能笼统宣称所有输入都满足
  60 dBc。
- 对长时间积分的弱谱线搜索，480/960/1440 MHz及其落入的PFB邻近bin必须视为已知
  污染区。固定项不会随积分下降，且跨ADC相干度最高接近0.99，可能进入互相关结果。
- Stage 33仍保持`RF_PARTIAL`：已完成的吞吐、同步、协议和大部分RF频带能力继续有效，
  但不能宣称三处固定RF邻域已经达到无条件科学动态范围。

## 已终止的候选修复路线

以下内容只记录本阶段停止前形成的候选设计，不是当前接续任务，也不授权生产实现。

### 若未来另立阶段时的前置条件

首先需要取得AMD支持的OCB1稳定或冻结方式。当前把读取到的OCB1原值写回形成override
只允许实验使用；没有器件支持依据时，不得作为生产状态长期保留。如果无法获得受支持
的稳定机制，本阶段不修改RTL，生产上只标记480/960/1440 MHz污染频点。

### 受控校准与前馈扣除

若OCB1稳定方式得到确认，建议按以下结构实现下一候选：

1. 八路ADC由可验证的50 Ω终端或射频开关进入校准状态，执行RFDC reset/MTS并等待
   温度与校准状态稳定。
2. 按板卡、ADC通道和480/960/1440 MHz估计固定复矢量；系数只在校准状态更新，科学
   观测期间冻结。160/1120/1280/1600 MHz在完成同等级定责前不加入扣除表。
3. 保留adapter输出处的未校正raw诊断tap；在正式preview/science分叉之前加入默认
   bypass的八路复矢量扣除模块，使PFB和正常监控看到同一校正数据。
4. NCO按`fixed_rf-center`生成基带频率，初相由全局`sample0`推进；160/320 MS/s模式
   共用物理RF定义，不引入新的UDP字段或时基。
5. 数据通路使用足够内部位宽并在既有IQ16边界舍入、饱和；不得引入`for_me.md`后续
   规划中的±8192 ADU限幅。

### 生产启用门禁

只有同时满足以下条件才能把bypass默认关闭：

- 八路ADC、160/320 MS/s两模式、20次reset/reconfigure和60分钟热稳定中，三条主线
  残余均不高于局部单bin噪声6 dB，且绝对值不差于`-90 dBFS`。
- 在480/960/1440 MHz逐点注入弱同频真实信号，扣除前后幅度误差不超过2%、相位误差
  不超过2°；证明固定系数不会把科学信号当作杂散删除。
- bypass路径bit-exact；启用后没有新增杂散、clip、RFDC drop、TIME/SPEC gap或
  `sample0`时间轴变化。
- 冷启动、overlay reload、LMK reload和MTS后可重复获得有效系数，不依赖人工观察
  选择“看起来最好”的一次状态。

任何一项未通过，均保持模块bypass并继续使用分析侧频点质量标记，不得用notch、隐藏
bin、降采样率或牺牲完整第一Nyquist通带掩盖问题。

## 已固化并清理的历史方法

本阶段曾使用 PFB 前 raw-preview 固定 RF/NCO 扫描、160/320 MS/s 全带扫描、43 窗口
原始 SPEC UDP 拼接、中心偏移复核、校准冻结、dither、OCB1 override A/B，以及静态
抵消模型。终止结论已将方法、数值和限制完整固化在本报告中；这些 Stage 33a 一次性
脚本和对应测试现已删除，不再提供复现入口。通用原始 SPEC UDP 解析与绘图工具保留为
`scripts/t510_plot_spec_udp_pcap.py`。
