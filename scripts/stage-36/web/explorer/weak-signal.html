复可见度幅度：每点100 ms

B = Σ nᵢ Vᵢ / Σ nᵢ
R = V − B
A = |R|

B：开启前OFF首60秒估计的固定复背景；i：训练桶索引；nᵢ：有效帧数；Vᵢ：训练桶复可见度。V：当前100 ms复可见度；R：扣除后复残差；A：残差幅度，单位count²；Σ：求和；| |：复数模。

原始曲线显示|V|。这是两路互相关幅度，不是单路功率。开启前OFF的0–60秒用于训练，60–120秒才是独立检验；ON和关闭后OFF均不参与拟合。

复可见度相位：每点100 ms

φ = atan2(Im R, Re R) × 180 / π

φ：相位，单位度；Re、Im：实部和虚部；atan2：保留象限的反正切；π：圆周率。原始相位用V代替R。零复数相位未定义，不绘制。

弱幅度下相位散开不代表性能改善。本页不做相位显著性筛选。±180°跳变可能只是角度绕回。
