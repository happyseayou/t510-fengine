复可见度幅度：每点100 ms

Bₛ = Σ nᵢ Vₛ,ᵢ / Σ nᵢ
R = V − B
A = |R|

s：所选状态；i：前60秒训练桶；nᵢ：桶内有效帧数；V：100ms复可见度；Bₛ：本状态复背景；B：选择的模板（原始时为0，固定时为B_A1，自身时为Bₛ）；R：复残差；A：幅度，count²；Σ为求和，| |为复数模。

先减实虚部再取模，不是幅度相减。图是两路复可见度幅度，不是自功率。固定A1模板作用于更早自然状态，只能作回顾比较。

相位：每点100 ms

φ = atan2(Im R, Re R) × 180/π

φ：相位（度）；Re/Im：实/虚部；atan2：保留象限的反正切；π：圆周率。零复数不画相位。低幅度相位散开不证明白噪声；本页无显著性筛选。

实部与虚部：每点10秒复均值

C = Σ nᵢ Rᵢ / Σ nᵢ

C：10秒加权复均值；i：该10秒内桶；nᵢ：有效帧数；Rᵢ：复残差。实线为Re C，虚线为Im C，单位count²。比较的是复数位置，而非只看幅度。

复平面：相同10秒均值的位置

横轴Re C，纵轴Im C，单位count²；两轴使用相同比例。按段内时间连接，不把不同状态连接为连续轨迹。A1与A2的位置接近才是复数意义上的返回。

两路自功率：每点10秒

Pₐ = Σ nᵢ Pₐ,ᵢ / Σ nᵢ

a：所选ADC对的第一路（第二路同理）；Pₐ,ᵢ：原始桶自功率；nᵢ：有效帧数；Pₐ：10秒加权自功率，count²。实线为该ADC对的第一路，虚线为第二路。背景扣除只作用于互相关，本图自功率不扣除。

全频结构：后60秒复均值的归一化幅度

ρ = 100 |C₆₀| / √(Pₐ Pᵦ)

C₆₀：该状态后60秒复均值减所选背景；Pₐ/Pᵦ：同段两路自功率；ρ：归一化幅度（%）。原始时为相关系数模；扣除后是归一化残差，不保证小于100%。每条4096点，无平滑。

B变化、A返回与段内波动：始终使用原始复数

α = (t_B − t_A1)/(t_A2 − t_A1)
D = B − [(1−α)A1 + αA2]
E = A2 − A1
J = median |Cⱼ₊₁ − Cⱼ|
显示值 = 100 |D或E| / N；100 J/N

A1、B、A2：对应状态后60秒原始复均值；t：检验段实际中点时刻；α：插值时间比例；D：B偏离线性插值A的复差；E：A返回复差；Cⱼ：检验段10秒原始复均值，j只在同段内相邻；J：三段共15个相邻差模的中位数；N=√(P̄ₐP̄ᵦ)，P̄为A1、A2检验自功率的算术平均。

全部单位%。J是描述性波动尺度，不是60秒均值标准误；超过J不代表显著。线性插值不能排除非线性漂移。
