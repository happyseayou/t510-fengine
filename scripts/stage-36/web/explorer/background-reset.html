RFDC reset 后，旧背景还能用吗？

三轮，每轮：旧背景60秒 → ADC Reset＋prepare/MTS → 新背景60秒 → 独立检验540秒。九段采集及验证全部通过；八路独立50 Ω、TG关闭。参数固定为60秒训练、逐bin复均值。

结论：新模板三轮均优于旧模板的整体评分，但不是每对都优于不扣除。强偏置可被明显压低；弱相关可能被模板估计误差或漂移影响。只研究参考输入下的偏置校正，尚未验证天文信号恢复。

540秒复可见度幅度（每点100ms）

每个点是什么

每轮5400个原生点，无抽样、插值或拼接。实部减实部、虚部减虚部后取模。可选择“扣新背景”放大查看残差。

R₀ = V
R旧 = V − B旧
R新 = V − B新
A = |R|

V：某一100ms桶的复可见度；B旧、B新：该轮重置前、后的60秒加权复均值；R：对应策略的复残差；A：残差幅度，单位count²；| |：复数模。

这是相关幅度，不是单路功率。取模总是非负，100ms点的平均幅度不等于先平均复数再取模。

540秒相位（每点100ms）

幅度与相位共用同一组点

φ = atan2(Im R, Re R) × 180 / π

φ：相位角，范围−180°到+180°；Re、Im：复残差实部、虚部；atan2：确定象限的角度函数；π：圆周率。零复数相位不定义，不画该点。

先扣复数再求角度，不直接减相位。幅度很小时相位会散开；本图不做显著性筛选，散开不证明白噪声或天文灵敏度恢复。±180°跳变可能只是角度绕回。

同一频点：每分钟复均值的残差

每条线九个点，是九个互不重叠的60秒段。背景不参与重新拟合，也不使用检验数据更新。

C = Σ nᵢ Rᵢ / Σ nᵢ
ρ = 100 |C| / √(Pa Pb)

C：该分钟加权复均值残差；i：100ms桶索引；nᵢ：桶内有效帧数；Rᵢ：对应策略的复残差；Pa、Pb：该分钟两路自功率；ρ：归一化残差模，单位%。
